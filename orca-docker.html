Run ORCA with Docker Desktop (local computer)

This workbench does not include ORCA. You must provide a Docker image that you are legally entitled to use and that contains a working ORCA installation. The following commands are run in the macOS Terminal, not in this webpage.

  1. Install and open Docker Desktop. Wait until Docker reports that its engine is running.
  2. In the Archichem project directory, install the local agent once:
./local-agent/install.sh

Start the local agent in a Terminal window. Replace the image placeholder with the name of your own ORCA Docker image:

ORCA_IMAGE=your-orca-image:tag .venv/bin/python local-agent/agent.py

The agent prints an API token. Keep this Terminal window open while submitting jobs. In the SIMONUSA Dashboard, configure the local API URL as http://127.0.0.1:8765 and paste the token. Then return here, select Docker local (MacBook), upload the .inp file and any required structure files, and submit.

Apple Silicon note: if your ORCA image is x86_64 only, start the agent with DOCKER_PLATFORM=linux/amd64 as well as ORCA_IMAGE=.... Emulation can be slower. The Docker image must contain ORCA and its runtime dependencies; SIMONUSA does not download or distribute ORCA.

Security: the local agent binds to 127.0.0.1. Do not expose it publicly or publish its token. Docker execution is local and is not a connection to BRIN HPC.

BRIN HPC access policy

Submission to a shared BRIN HPC account remains disabled. It requires individual student authentication, isolated working directories, job limits, and HPC administrator approval. Never put an HPC password or private SSH key in GitHub Pages.
